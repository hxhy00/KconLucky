## 1. 背景与目标
### 1.1 业务背景
- KCon 2026（10月31日·中关村国际创新中心）与 GAi+C 大会同场举办。
- 票务走多平台：嘶吼（主力）、TGO、崔牛会、活动行，另有对公票、赠票、VIP/嘉宾/媒体票。
- 票以电子票为主，票源区分靠「名单归集 + 渠道标识」，不靠票面打码。
### 1.2 工具目标
1. 大会当天**观众自助签到**：手机扫码 → 输手机号（支持后四位）或姓名 → 自动识别票源渠道 → 点签到。
2. 签到即分配**唯一随机端口号（1-65535）**作为抽奖号，大字号展示并提示截图保存。
3. **管理端**：名单管理（上传/追加/替换）、签到实时监控、数据导出。
4. **抽奖端**：大屏滚动抽号，支持上午场/下午场分场次、一号只中一次、作废重抽、兑奖核验防伪造。
5. 全程**本地部署**：会场一台笔记本运行，数据不出本机。

## 3. 范围
**范围内**：观众签到、端口号分配、名单管理、实时看板、分场次抽奖、作废重抽、兑奖核验、数据导出。
**范围外**：① 与各售票平台的 API 对接（名单靠 Excel 人工汇总导入）；② 线上售票/收款；③ 闸机/人脸识别等硬件；④ 微信小程序上架（用 H5 网页实现同等体验）。

## 5. 非功能需求
| 类别 | 需求 |
|---|---|
| 部署 | 会场一台笔记本运行（Mac/Windows 均可，仅需 Python 环境）；手机与笔记本同一会场 WiFi |
| 网络 | 不依赖外网；数据查询走本地，建议备手机热点兜底 |
| 性能 | 单文件并发支撑 300-500 人现场签到（瞬时并发低），抽奖单点操作 |
| 数据安全 | 所有数据仅存本机（CSV/JSON 文件），不上传任何外部服务器；会后按合规要求加密存档或销毁 |
| 隐私 | 管理台与核验结果中手机号一律掩码显示（138****0001） |
| 可用性 | 观众端页面极简，三步完成签到；操作失误（输错号）有明确引导 |
| 可恢复 | 签到/端口/中奖数据实时落盘，断电重启不丢 |

## 6. 接口与数据
### 6.1 输入
- 票务名单：Excel/CSV（姓名、手机号、渠道标识、票种），由各渠道日报汇总而来。
### 6.2 数据文件（应用同目录）
| 文件 | 内容 |
|---|---|
| attendees.csv | 票务总表 |
| signed.json | 签到记录（手机号→时间+日期） |
| ports.json | 端口号分配（手机号→端口号） |
| winners.json | 中奖记录（含场次） |
| session.json | 当前场次与截止时间 |
### 6.3 输出
- 导出签到 Excel（含中奖标记），供会后核对与存档。
---
## 7. 约束与依赖
1. 运行环境：Python 3 + openpyxl 库（导出/模板用）。
2. 名单质量依赖：各渠道必须提供**手机号字段**（核验主键），缺手机号的渠道无法自助签到。
3. 现场需申请网络专线 + 备 4G 路由；同场 GAi+C 大会人员混场，临时来宾走人工通道。
4. 观众与笔记本必须同一 WiFi 网段（无访客隔离）。

## 8. 验收标准
| 编号 | 验收项 | 通过标准 |
|---|---|---|
| AC-01 | 手机号签到 | 输入名单内手机号→显示姓名/渠道/票种→签到成功→获得端口号 |
| AC-02 | 后四位签到 | 唯一尾号可签到；重名尾号提示输完整手机号 |
| AC-03 | 姓名签到 | 输姓名列出候选→选"是我"→正常签到 |
| AC-04 | 端口号 | 全场唯一、范围1-65535、重复签到不变号 |
| AC-05 | 上传名单 | 追加去重、替换生效、错误表头有提示 |
| AC-06 | 场次抽奖 | 上午场只含上午截止前签到者；下午场只含下午截止前签到者；切场即刷新可抽数量 |
| AC-07 | 一号一中 | 已中奖号再抽100次不出现 |
| AC-08 | 作废重抽 | 作废后号码回池且可再次中奖 |
| AC-09 | 兑奖核验 | 有效号返回持有人信息；伪造号提示拦截 |
| AC-10 | 断电恢复 | 重启后签到/端口/中奖数据完整 |

## 10. 风险
| 风险 | 应对 |
|---|---|
| 某渠道名单缺手机号 | 提前与各渠道确认字段；缺失者走人工通道 |
| 现场 WiFi 访客隔离导致观众连不上 | 提前用测试机验证；备手机热点 |
| 截图造假冒领 | 兑奖核验+报姓名/尾号双重核对 |
| 同名同姓被冒签 | 姓名签到需选"是我"；兑奖核手机尾号兜底 |
| 多人同时抽奖操作 | 抽奖端仅1人操作（主持人），不支持多端并发控制（口头约定即可） |
