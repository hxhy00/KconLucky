# KCon 2026 自助签到小应用 · 使用说明（v4 · 截图兑奖版）
## 这是什么
一个手机扫码即用的签到 + 抽奖小工具：
- **观众端**：扫码 → 输入手机号（支持后四位）→ 自动识别票源渠道 → 点签到 → **系统分配随机端口号（1-65535），大字号显示，提示观众截图保存**
- **管理端**：自动打钩 + 签到时间 + 端口号，支持上传 Excel、持续追加、导出 Excel
- **抽奖端**：大屏滚动抽号 → 定格中奖端口号 → 一号只中一次 → 支持作废重抽 → **内置兑奖核验（防伪造截图）**
## 完整流程
```
观众扫码 → 输手机号（或后四位）→ 识别票源渠道 → 点"确认签到"
    ↓
屏幕大字显示【抽奖端口号】+ 提示"请务必截图保存"
    ↓
大会抽奖环节 → 打开抽奖页 → 点"🎁 抽奖" → 大屏滚动 → 定格中奖端口号
    ↓
中奖人凭截图上台 → 工作人员用"兑奖核验"输入端口号核对持有人姓名/尾号 → 兑奖
```
> 💡 忘记截图？重新输入手机号即可再次查看（端口号与手机号绑定，不会变）。
## 大会当天怎么用（4步）
### 第1步：启动应用
笔记本上运行 `python3 app.py`，看到"已启动"就成功，**窗口别关**。
### 第2步：上传票务名单
管理台 `http://127.0.0.1:8000/admin` → "📥 上传票务名单" → 选 Excel/CSV → 选"追加"模式上传。
表头需含：**姓名 / 手机号 / 渠道标识 / 票种**（渠道标识：S嘶吼 T-TGO C崔牛会 H活动行 D对公 G赠票 V嘉宾）
### 第3步：观众签到
管理台顶部显示**观众签到地址**（如 `http://10.0.191.144:8000/`），做成二维码水牌放签到台，或提前微信发给观众。
观众扫码 → 输手机号 → 点签到 → 看到端口号并截图保存。
### 第4步：现场抽奖 + 兑奖核验
抽奖页面：`http://10.0.191.144:8000/lottery`（建议投大屏）
1. 点"🎁 抽奖" → 号码滚动约1秒定格 → 显示中奖端口号 + 姓名 + 渠道
2. **已中奖的号自动移出抽奖池，一号只中一次**
3. 中奖人不在场？点该条记录旁的 **✕ 作废** → 号码回到抽奖池，可重抽
4. 兑奖时：在页面底部"**🔍 兑奖核验**"输入端口号 → 显示持有人姓名、手机掩码、渠道、是否中奖 → 让领奖人报出姓名或尾号核对后再兑奖
## 关键规则
| 规则 | 说明 |
|---|---|
| 端口号范围 | 1-65535，每位签到观众唯一分配，互不重复 |
| 端口号不变 | 同一手机号重复查询/签到，端口号保持不变 |
| 一号一中 | 已中奖端口号不再参与后续抽奖 |
| 作废重抽 | 中奖人缺席可作废该条记录，号码回池重抽 |
| 兑奖核验 | 未发放的端口号会被标记"可能为伪造截图" |
| 后四位签到 | 仅当尾号唯一时可用；多人同尾号会提示输完整手机号 |
## 管理台功能一览
| 功能 | 说明 |
|---|---|
| 📥 上传名单 | Excel/CSV，追加或替换模式，即时生效 |
| 实时统计 | 总人数 / 已签到 / 未签到 / 签到率 / 各渠道进度 |
| 抽奖号列 | 每人的端口号一目了然 |
| 导出Excel | 含抽奖端口号列（兑奖留档） |
| 🎁 抽奖页面 | 一键跳转现场抽奖大屏 |
## 注意事项
1. **手机和笔记本必须连同一个 WiFi**，否则观众打不开页面
2. 抽奖页建议**投大屏/投影**，氛围最好
3. **数据只在本地**：signed.json / ports.json / winners.json 都在应用目录，会后按合规要求存档或销毁
4. 清空重来：删除上述三个 json 文件后重启即可
## 常见问题
| 问题 | 解决 |
|---|---|
| 观众打不开页面 | 检查同一 WiFi；防火墙允许 8000 端口 |
| 抽奖显示"还没有人签到" | 正常状态，等观众签到后即可抽 |
| 尾号查不到 | 两人尾号相同时需输完整手机号 |
| 中奖人不在场 | 点该记录 ✕ 作废，再重新抽奖 |
| 有人P图冒领 | 用"兑奖核验"输入端口号，核对持有人姓名/尾号 |
