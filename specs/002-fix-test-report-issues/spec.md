# 002 修复线上测试发现的问题

## 背景与问题（必填）

2026-10-15 对线上服务器 `123.56.72.135` 的三端测试（留档：`KCon2026-核销日志-测试留档/KCon2026-测试报告.md`）发现 8 个问题。经用户确认：

- 问题 2（验证码关闭）为**测试所需，有意为之**，不修
- 问题 7（全量导出含整库）为**设计如此**且仅超管可操作，不修
- 其余 6 个问题需修复

## 对应需求

- FR-16（抽奖设置）、FR-26/FR-12（导出与模板）、FR-15/FR-39（场次与统计口径）

## 修复清单

| 测试报告编号 | 问题 | 修复方式 |
|---|---|---|
| 1 | swagger `/v3/api-docs`、`/swagger-ui/**` 未登录可访问 | `springdoc.api-docs.enabled=false` + `swagger-ui.enabled=false` |
| 3 | `POST /admin/draw/setting` 空 body 误清赞助商 | 区分「缺 sponsors 字段」与「显式清空」：缺字段时拒绝，不修改 |
| 4 | 清场不复位 `kcon_session.status` | `reset()` 增加 `deactivateAll()`，把场次状态复位为 0 |
| 5 | 导入模板含「端口号」列但导入时被忽略 | `KconAttendee.portNo` 的 `@Excel` 限定 `Type.EXPORT`，模板不再生成该列 |
| 6 | 重复提交提示「不允许重复提交，请稍候再试」易误解 | 默认文案改为「操作过于频繁，请稍候再试」 |
| 8 | 签到输入不支持全角数字 | H5 输入全角→半角归一化后再校验 |

## 验收标准

- [ ] 未登录访问 `/v3/api-docs`、`/swagger-ui/index.html` 返回 404
- [ ] 空 body / `{}` 提交抽奖设置返回明确错误，赞助商不被清空；`{"sponsors":""}` 仍可显式清空
- [ ] 清场后 `kcon_session.status` 全部为 0
- [ ] 导入模板不再含「端口号」列；导出仍含
- [ ] 重复提交提示为新文案
- [ ] 全角数字 `１３８１０２４６７３１` 可正常签到查询
