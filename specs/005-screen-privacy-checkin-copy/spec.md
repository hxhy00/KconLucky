# 005 大屏隐私收紧 + 签到成功页兑换引导

## 1. 问题定义

- **谁在什么场景**：KCon 现场抽奖，大屏投在会场主幕布上，全场观众可见。
- **问题 A（大屏）**：三处信息暴露过度——
  1. 揭晓定格与汇总页显示中奖者**姓名**，观众可对应到真人（隐私顾虑）；
  2. 顶部统计「今日已签到 / 可抽号数 / 已中奖」实时暴露运营数据，主办方不希望全场盯数字。
- **问题 B（签到 H5）**：签到成功页文案偏「领胸牌」，观众对端口号的核心用途——**参与抽奖、兑换礼品**——认知不足，散场后有人不知道号码干嘛用。

## 2. 需求规格

### 大屏（screen）
- **不做清单**：管理端「抽奖控制台」的三项统计**保留**（工作人员需要看数据），只收大屏。
- 移除顶部三个统计块，头部只留 logo + 场次徽章。
- 揭晓定格后只显示端口号，不显示姓名。
- 汇总页 winner-grid 只显示端口号，不显示姓名。
- 揭晓文案「第 x / y 位」保留；汇总页数字布局在去掉姓名后保持可读（单列端口号加大）。

### 签到 H5（checkin-h5 成功页）
- 主文案改为围绕「抽奖凭证 + 兑换礼品」：
  - 「您的抽奖端口号为」+ 大号号码（保留）
  - 引导语改为：**请截图保存此号码，凭它参与现场抽奖；中奖后凭此号码到礼品区兑换奖品**
  - 保留「出示截图领胸牌」提示（次要动作，放次要位置）

## 3. 验收标准
- [x] 大屏顶部无「今日已签到 / 可抽号数 / 已中奖」三个统计
- [x] 大屏揭晓定格、汇总页均不出现中奖者姓名（产物 grep 无 `winner-name`）
- [x] 签到成功页强调端口号用于抽奖与兑奖，胸牌提示降为次要样式仍可见
- [x] 管理端统计不受影响（`ruoyi-ui` 未改动）
- [x] `npm run build`（screen / checkin-h5）通过
