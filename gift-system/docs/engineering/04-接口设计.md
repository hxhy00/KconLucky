# KCon2026 赠票系统 接口设计
| 项 | 内容 |
|---|---|
| 文档编号 | KCON-API-001 |
| 版本 | V1.0 |
| 协议 | HTTP/1.1 + JSON |
| 认证 | Header `X-Session: <sid>` |
---
## 1. 通用约定
### 1.1 响应格式
**成功**
```json
{ "ok": true, "msg": "操作成功", "data": { } }
```
**失败**
```json
{ "ok": false, "msg": "具体错误原因" }
```
### 1.2 HTTP 状态码
| 码 | 含义 | 场景 |
|---|---|---|
| 200 | 成功 | 业务处理完成（含业务失败，看 `ok` 字段） |
| 401 | 未登录 | 无 Session 或已过期 |
| 403 | 无权限 | 角色不符或跨渠道越权 |
| 404 | 不存在 | 资源不存在 |
| 429 | 限流 | 频率超限 |
| 500 | 服务异常 | 未捕获异常 |
### 1.3 鉴权中间件
```
X-Session → 查会话表 → 校验过期 → 校验角色 → 注入 actor 上下文
```

## 2. 接口清单（共 24 个）
### 2.1 认证（4）
| # | 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|---|
| 1 | POST | `/api/auth/send-code` | 无 | 发送验证码 |
| 2 | POST | `/api/auth/login` | 无 | 验证码登录 |
| 3 | POST | `/api/auth/logout` | 有 | 登出 |
| 4 | GET | `/api/me` | 有 | 当前用户信息 |
**1. send-code**
```
请求: { "email": "admin@kcon.com" }
响应: { "ok": true, "msg": "验证码已发送", "demo_code": "123456" }
错误: 邮箱格式错 / 60 秒内重发 / 单日超 20 次
```
**2. login**
```
请求: { "email": "...", "code": "123456" }
响应: { "ok": true, "role": "admin", "user": {...}, "sid": "32位" }
错误: 验证码错误(剩 N 次) / 已过期 / 锁定 / 无系统权限
```
### 2.2 管理员（6）
| # | 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|---|
| 5 | GET | `/api/admin/stats` | admin | 全局统计 |
| 6 | GET | `/api/admin/channels` | admin | 渠道列表 |
| 7 | POST | `/api/admin/channels` | admin | 创建渠道 |
| 8 | POST | `/api/admin/channel/suspend` | admin | 停用渠道 |
| 9 | POST | `/api/admin/channel/delete` | admin | 物理删除（仅空渠道） |
| 10 | POST | `/api/admin/staff` | admin | **v1 不对外暴露**（签到由下游负责，路由已移除） |
| 25 | POST | `/api/admin/approver/replace` | admin | 更换渠道审批员 |

**25. 更换审批员**
```
请求: {
  "channel_id": 1,
  "approver_name": "李接替",   // 2-20
  "approver_email": "new@x.com" // 邮箱，未被其他渠道占用
}
响应: { "ok": true, "msg": "审批员已更换为「李接替」，作废旧令牌 N 个，重签发 M 个" }
错误: 渠道不存在 / 渠道已停用 / 该邮箱已被其他渠道使用 / 该邮箱已是本渠道审批员
副作用: 停用原审批员→新建→作废旧令牌→给待审批推荐人重签令牌发M-02→发M-01通知新人
```
**7. 创建渠道**
```
请求: {
  "name": "知道创宇安全团队",     // 2-50，唯一
  "approver_name": "张明",        // 2-20
  "approver_email": "z@k.com",   // 邮箱，唯一
  "quota": 100,                   // 1-500
  "referrer_cap": 20,             // 1-100
  "remark": ""                    // 可选
}
响应: { "ok": true, "msg": "渠道创建成功，已发送开通邮件" }
错误: 名称重复 / 邮箱已被使用 / 配额超范围 / 渠道数已达 20 上限
```
### 2.3 审批员（4）
| # | 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|---|
| 11 | GET | `/api/approver/overview` | approver | 工作台概览 |
| 12 | GET | `/api/approver/referrers` | approver | 本渠道推荐人 |
| 13 | GET | `/api/approver/recipients` | approver | 本渠道接收人 |
| 14 | POST | `/api/approver/referrer/approve` | approver | 审批推荐人 |
**14. 审批推荐人**
```
请求: { "id": 1, "action": "approve" }   // approve | reject
响应: { "ok": true, "msg": "已通过「张三」的推荐人注册" }
错误: 无权操作该推荐人(403) / 已处理 / 令牌失效
```
### 2.4 公开注册（2）
| # | 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|---|
| 15 | POST | `/api/referrer/register` | 无 | 推荐人注册 |
| 16 | POST | `/api/ticket/register` | 无 | 接收人注册 |
**16. 接收人注册（5 项提交时校验）**
```
请求: {
  "referrer_code": "16位",
  "name": "王参会", "company": "某银行",
  "mobile": "139...",   // 可选
  "email": "w@bank.com"
}
响应: { "ok": true, "msg": "申请已提交，等待推荐人确认" }
错误（全部在提交时返回）:
  - 该邮箱已由「XX」推荐注册，请勿重复提交
  - 您已为该邮箱提交过申请，当前状态：已通过
  - 该邀请链接赠票已发完（上限 20 张），请联系推荐人
  - 本渠道赠票已发完，请联系渠道负责人
  - 该邀请链接已失效
```

## 3. 错误码字典
| 错误消息 | 触发条件 | HTTP |
|---|---|---|
| 邮箱格式不正确 | 正则不匹配 | 200 |
| 请 N 秒后再试 | 60 秒内重发 | 200 |
| 今日验证码发送次数已达上限 | 单日 > 20 | 200 |
| 验证码错误，还可尝试 N 次 | 校验失败 | 200 |
| 验证码错误次数过多，请重新获取 | 失败 ≥ 5 | 200 |
| 该邮箱无系统权限 | 不在白名单 | 200 |
| 未登录或会话已过期 | 无/过期 Session | 401 |
| 无权限 | 角色不符 | 403 |
| 无权操作该推荐人 | 跨渠道 | 200 |
| 渠道名称已存在 | 唯一冲突 | 200 |
| 该邮箱已被其他渠道使用 | 唯一冲突 | 200 |
| 渠道数量已达上限（20） | 规模约束 | 200 |
| 该邀请链接已失效 | 推荐人非通过/渠道停用 | 200 |
| 该邀请链接赠票已发完（上限 N 张） | 单人上限 | 200 |
| 本渠道赠票已发完 | 渠道配额 | 200 |
| 该邮箱已由「XX」推荐注册，请勿重复提交 | 邮箱唯一 | 200 |
| 链接无效 / 已被使用 / 已过期 | 令牌校验 | 200 |
| 注册码无效，请核对 | 编码不存在 | 200 |
| 该参会人已于 XX 完成签到 | 重复签到 | 200 |
| 该赠票尚未生效 / 已被拒绝 / 已作废 | 状态不符 | 200 |

## 4. 限流策略
| 接口 | 限制 | 维度 |
|---|---|---|
| `/api/auth/send-code` | 60 秒 1 次，单日 20 次 | 邮箱 |
| `/api/referrer/register` | 每小时 10 次 | IP |
| `/api/ticket/register` | 每小时 20 次 | IP |
| `/api/checkin/lookup` | 每秒 20 次 | IP |
| 其他写接口 | 每秒 10 次 | IP |
