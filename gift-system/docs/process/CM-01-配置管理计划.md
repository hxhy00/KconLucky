## 4. 变更控制
### 4.1 变更流程
```mermaid
flowchart TD
    A["变更申请 CCB"] --> B["影响分析<br/>范围/成本/进度/质量"]
    B --> C{"CCB 审批"}
    C -->|拒绝| D["关闭"]
    C -->|批准| E["修改配置项"]
    E --> F["回归测试"]
    F --> G{"测试通过?"}
    G -->|否| E
    G -->|是| H["更新基线"]
    H --> I["通知相关方"]
    I --> J["关闭"]
```
