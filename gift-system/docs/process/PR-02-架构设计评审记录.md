## 4. 评审结论
- [x] **通过**（7 个问题全部关闭）
### 4.1 关键决策确认
| 决策 | 结论 | 理由 |
|---|---|---|
| D1 SQLite 单库 | ✅ 采纳 | 500 票规模单机足够，零运维 |
| D2 标准库 http.server | ✅ 采纳 | 无框架依赖，覆盖率统计简单 |
| D3 领域层纯函数 | ✅ 采纳 | 无 Mock 单测，覆盖率易达 100% |
| D4 Clock/Random 抽象 | ✅ 采纳 | 测试确定性 |
| D5 邮件 outbox 模式 | ✅ 采纳 | 测试可断言，不真发信 |
| D6 外部签到空实现 | ✅ 采纳 | 甲方未定接口，先隔离 |
| D7 单进程 + 线程池 | ✅ 采纳 | 10 次/秒足够，避免 SQLite 写锁 |
### 4.2 遗留风险
| 风险 | 影响 | 缓解 |
|---|---|---|
| SQLite 写锁（高并发签到） | 理论上有锁等待 | WAL 模式 + busy_timeout 5 秒 |
| 内存会话（重启丢失） | 用户需重新登录 | 会议期间不重启；如需多实例改 Redis |
